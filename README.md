# Feign 盤面整理支援ツール

このツールはFork元であるsawa90さんのfeign-support-toolを改修したものです。  
元ツール : https://sawa90.github.io/feign-support-tool/  
リポジトリ : https://github.com/sawa90/feign-support-tool  

## 使用方法（概要）

1. ページの下部でプレイヤー全員の名前を入力して設定
    * 必要に応じて表示用ウィンドウを開く  
![説明1](docs/images/readme/readme_1.png)
2. 左端の列（名前の左）をクリックして各プレイヤーの色を設定  
![説明2](docs/images/readme/readme_2.png)
3. 盤面情報を記録（役職、行き先、行動結果など）  
![説明3](docs/images/readme/readme_3.png)
