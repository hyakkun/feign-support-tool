# ローカル画像プレビューブランチの扱い

## 対象ブランチ

`feature/local-role-images-preview` は、トラッカ、魔術師、ホーンタの暫定画像をローカル環境だけで確認するためのブランチである。

このブランチは、次のローカル未追跡ファイルを参照する。

- `public/image/Tracker.png`
- `public/image/Magician.png`
- `public/image/Haunter.png`

これらの素材は作成者・利用条件の確認が完了していないため、`.gitignore` の対象であり、Git管理・リモート公開の対象ではない。

## 必須ルール

- `feature/local-role-images-preview` を `master` へマージしない。
- 当該ブランチの画像参照コミットを `master` へ cherry-pick しない。
- 当該ブランチをリモートへ push しない。
- 暫定画像ファイルを force-add したり、`.gitignore` から除外したりしない。

このルールは、画像ファイルなしで参照コードだけが公開され、公開版で画像欠落が起きることを防ぐためのものである。

## 将来の取り込み条件

素材作成者から利用許諾を得て、ライセンスまたは利用条件をリポジトリ内に記録できた場合に限り、次の手順で改めて取り込む。

1. `master` から新しい通常ブランチを作成する。
2. 許諾済みの画像と出典・利用条件をGit管理に追加する。
3. 画像参照コードを新しいブランチへ必要最小限で再実装する。
4. ローカル表示、ビルド、ライセンス記載を確認する。
5. レビュー後に通常の手順で `master` へ統合する。

許諾前は、`master` では役職名のテキスト表示を正とする。
