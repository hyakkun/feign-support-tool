# 公開版との差分と基準機能

## 参照した版

| 用途 | Git参照 | 内容 |
| --- | --- | --- |
| 現在の開発版 | `master` (`2c43e89`) | このリポジトリで編集するReactソース |
| 公開済み成果物 | `archive-gh-pages-2022-02-25` (`feaf465`) | GitHub Pagesで公開されている静的ファイルの固定タグ |
| 回復用ソース | `recovery/gh-pages-2022-02-25` (`ac09770`) | 成果物のソースマップから復元した`src/index.js`と`src/index.scss` |

`gh-pages`はデプロイ済み静的ファイルのみを含み、元の`package.json`は含まない。ただし、JavaScriptとCSSのソースマップには完全な`index.js`と`index.scss`が埋め込まれていた。回復用ブランチは比較・移植のための参照であり、そのままデプロイしない。

## 機能差分

| 領域 | 現在の開発版 | 公開版 | 後続作業での扱い |
| --- | --- | --- | --- |
| 初期画面 | 説明用の2行・1日分の盤面 | 色、役職、固定行を含むチュートリアル盤面・2日分の列 | 維持する。公開版を基準として初回利用者向けに保つ |
| 行動種別 | 数値リテラルを直接利用 | `action`、`role`、`name`、`created`、`option`の定数を定義 | 採用する。役職カタログ化の前提として数値の意味を定数化する |
| 陣営の初期選択 | 役職選択時は原則として未確定 | 役職ごと・入力欄ごとの既定陣営を持つ | 公開版の挙動を回帰対象にする。役職定義に移す |
| ルック／インベ入力 | 一般的な複数選択メニュー | 選んだ役職に応じ、プレイヤー名または役職入力を補助する | 保持対象。役職固有の入力ルールとして明文化する |
| 追放・殺害 | 通常の選択メニュー | 専用の`DeadSelect`で対象プレイヤーと死亡役職を連動させる | 重要な保持対象。盤面データ更新の回帰テストを作る |
| 死亡役の視覚化 | 通常表示 | 対象行への役職移動アニメーション | UI改善項目として保持候補。最初の役職追加では動作維持を優先し、実装方式は後で見直す |
| 盤面の行 | プレイヤー行と固定イベント行 | 任意のメモ行を追加可能 | 維持する |
| 補助ウィンドウ | なし | `popup.html`／`popup.js`へ盤面情報を送る別ウィンドウ | 維持する。移植時にブラウザのポップアップ制約も確認する |
| 役職選択UI | 選択直後に更新しやすい単純構成 | 複数入力を続け、メニューを閉じた時点で確定する構成 | 公開版の入力フローを手動確認し、採用する振る舞いをテスト化する |
| 固定イベント行 | `追放`、`殺害`、`爆発`、`医者`、`挑発`、`対立`、`ﾗｲﾝ` | `追放`、`殺害`、`爆発`、`医者`、`対立`、`ﾗｲﾝ` | 固定行`挑発`は削除し、`自爆`・`道連れ`を追加する。役職「プロボカ」は行動履歴で扱う |
| 公開方法 | `npm run deploy`で`gh-pages`へ出力する設定 | `gh-pages`がリモート既定ブランチで、成果物のみを管理 | ソース用ブランチとデプロイ先を分離する。回復・移植が完了するまで公開しない |

## 暫定方針

1. 公開版で提供済みの盤面編集機能は、廃止を決めない限り保持対象とする。
2. 公開成果物を`master`へ直接マージまたはデプロイしない。必要な機能だけを、回復ブランチを参照して移植する。
3. 役職追加前に、死亡処理・役職固有の入力補助・既定陣営をテスト可能な仕様として切り出す。
4. 補助ウィンドウ、チュートリアル盤面、メモ行は公開版の機能として維持する。固定イベント行`挑発`は復元しない。

## 追加役職の要件

| 役職ID（案） | 表示名 | 陣営 | 入力・結果 | 公開情報・盤面上の表現 |
| --- | --- | --- | --- | --- |
| `tracker` | トラッカ | 緑または赤 | 対象プレイヤーを選ぶ。行き先は人物、在宅などで見えない場合は既存の`×`結果 | 行き先の人物または既存の`×`を記録する |
| `magician` | 魔術師 | 青 | 対象プレイヤーを選び、役職を予想する。的中時は対象をキルし、失敗時は自身が自爆する | 自爆行で人物を記録すると、死亡役欄へ魔術師を自動記録する |
| `haunter` | ホーンタ | 青 | 対象の家へろうそくを置く。自身が追放された時、対象を道連れにできる | ろうそくは任意メモで記録し、道連れ行には対象だけを記録する。旧称「ホーンター」「ゴースト」は移行用の別名として扱う |

## 役職追加時の受け入れ条件

- トラッカは対象と行き先の人物入力を混同せず、在宅などで人物が見えない場合は既存の`×`を使える。
- 魔術師の的中キルと自爆は別々の固定行として記録できる。自爆の人物選択時には魔術師を死亡役欄へ自動記録する。
- ホーンタのろうそくは任意メモで記録し、追放行と道連れ行を盤面上で見比べて考察できる。実行者との関係は記録しない。
- 既存の盤面・公開版から維持する機能の入力を壊さない。
